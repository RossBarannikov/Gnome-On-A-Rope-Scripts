# Gnome on a Rope 🎮

A mobile action game developed in Unity featuring custom C# rope physics simulation, interactive mechanics, and game state management.

## 🛠️ Code Structure & Features
- **C# Gameplay Scripts:** Located in the `/Scripts` folder.
- **Rope Physics:** Dynamic length controls and rope physics simulation.
- **State Management:** Main menu UI, game-over conditions, and scene reloads.
